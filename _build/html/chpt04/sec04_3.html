4.3. Violações dos padrões de qualidade do ar no Brasil

4.3. Violações dos padrões de qualidade do ar no Brasil#

Utilizando o meno abaixo, é possível visualizar os dados de cada estação de monitoramento da qualidade do ar no Brasil nos respectivos tempos de média para cada poluente listado na CONAMA 506/2024. São disponibilizados os registros das estações no banco de dados montado neste relatório. O sistema monta uma tabela com as estatísticas de excedências dos padrões de qualidade do ar, conforme a resolução.

Dica

Você pode escolher a janela temporal para atualizar a figura e tabela de excedências.





Aviso

Não obtivemos o registro histório de todas as estações de monitoramento instaladas no Brasil.
